# Packet P7-ANCHORS: calibration-aware assignment + estimability meter

Motivation (measured): on the fixture's design judge offsets are not estimable (permutation p = 0.381; CV picks λ = 100). Fix it at design time.
1. `src/judging/assign.py`: optional `anchors_per_track: int = 0`. Before the normal greedy fill, pick that many anchor projects per track (deterministic: seeded, prefer projects with the most eligible judges) and assign every eligible, non-conflicted judge of that track to them (respect max_load by counting anchors first; report if anchors make the target infeasible). Output marks anchor assignments.
2. `src/results/engine.py` (pure): `estimability(design, sigma_noise=15.0, bias_grid=(4, 8, 12), reps=200, seed)` where design = list of (judge, project) pairs → per judge: expected SE of the offset under the shrinkage model (by seeded simulation of the additive model with the design), and detection power for each bias size (share of reps where the injected judge's fitted offset exceeds 2 SE). Event-level summary: median SE, power at 8 points. Fast enough for 30 judges × 40 projects (< 3 s).
3. Proof section "Designing for calibration": same review budget (≈121 reviews), fixture design vs anchor design (anchors_per_track = 1 or 2, reducing other assignments to keep the budget): compare power to detect an 8-point judge bias and rank recovery (Spearman with truth) under σ_b = 0.6. Report whatever the numbers are.
4. Service/API (after P2-RX/OUI are merged): `POST /events/{slug}/assignments/auto` accepts `anchors_per_track`; response includes the estimability summary for the proposed design; `GET /events/{slug}/estimability` for the current design (organizer). UI: shown on the assignments page next to the preview (OUI follow-up).
Tests: anchors assigned to every eligible judge of the track; conflicts respected; deterministic; estimability SE shrinks as overlap grows; power increases with anchors on a synthetic design.
Files: src/judging/assign.py, src/results/engine.py, scripts/normalization_proof.py, docs/NORMALIZATION-PROOF.md, tests/test_assignment.py, tests/test_engine.py (+ API bits in src/judging/{services,api,api_urls}.py in step 4).
