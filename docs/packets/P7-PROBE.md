# Packet P7-PROBE: live integrity probe (self red-team), extends P5-EVIDENCE

- `src/core/probe.py`: a list of named attack cases, each = (tier/area, description, method, path template, actor role, body, expected statuses, why it must fail). Covers: peer scores by path and by `?judge=`, reading an unassigned project's private answers as a judge, writing a review for another track's project, writing a review after judging closes (using a disposable probe event), participant writes after the deadline (create/update/images/answers/team join), other team's draft by id, draft media by guessed URL, organizer of event A reading event B's reviews/exports, CSV export as judge/participant, anonymous API (expects 401), CSRF-less session POST (expects 403), revoked token reuse, results/tallies during a voting window (once T3 exists), CSV formula injection neutralised in exports.
- Runner executes each case with Django's test `Client` against the real URL routing and middleware (not by calling services directly), using **temporary tokens created for the probe and revoked afterwards**, in a disposable event it creates and deletes, inside `transaction.atomic()` rolled back at the end so production data never changes. Records an AuditEvent `integrity.probe_run` with the pass/fail summary.
- `manage.py integrity_probe [--json]` prints `AREA  description ..... REFUSED 403 (expected 403)` lines like run.py; writes `attack-report.txt` when `--write`.
- Organizer/admin page `/admin-panel/integrity` (admin) and `/manage/{slug}/integrity` (organizer; runs cases scoped to their event): "Run probe" button (POST API `POST /api/v1/integrity/probe`), results table with request, actor, expected, actual, and a one-line reason each.
- `scripts/attack.py` (stdlib, external): the same cases over real HTTP against a running portal using `.dogfood.toml` tokens; and `scripts/verify_tiers.py` per P5-EVIDENCE.
Tests: every case currently passes (refused as expected); a deliberately broken policy stub makes the corresponding case fail (the probe really detects leaks); probe leaves no rows behind; non-admin/non-organizer → 403.
Files: src/core/probe.py, src/core/management/commands/integrity_probe.py, probe API/view/template, scripts/attack.py, scripts/verify_tiers.py, tests/test_probe.py.
