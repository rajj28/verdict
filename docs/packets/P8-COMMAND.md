# Packet P8-COMMAND: judging command center (pace forecast + rebalance)

Pure function src/judging/forecast.py: per judge, from submitted review timestamps (live reviews only; imported ones have no real timing and are excluded, say so) → median minutes per review (robust: median of gaps < 60 min between consecutive submits), remaining assignments, projected finish = now + remaining × pace; event-level projection = latest judge finish; at-risk if projected finish > judging_close_at, or no review submitted after X hours since first assignment ("not started"). Rebalance proposal: move unstarted assignments (no draft, no submission) from at-risk judges to same-track, non-conflicted judges with the earliest projected finish, keeping max_load; preview + apply (atomic, audited, AssignmentBatch method "rebalance"). API: GET /events/{slug}/command-center, POST /events/{slug}/assignments/rebalance {dry_run}. Organizer page shows the forecast table, a timeline bar per judge and the proposal. Tests: pace from synthetic timestamps, at-risk detection, rebalance respects tracks/conflicts/load and never moves drafted or submitted work, determinism.
