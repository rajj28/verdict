# Packet P7-PLANNER: review-budget planner, organizers' σ chain, λ NaN fix (engine + proof only)

Decision (orchestrator, Sun 27 Sep): the anchors experiment showed that at the fixture's budget no assignment pattern makes judge bias detectable (power ≈ 0.13 at 8 points) because each judge writes ~4 reviews. The flagship becomes an **estimability meter + review-budget planner**.
1. `engine.review_budget_curve(n_judges, n_projects, reviews_per_judge_grid=(3,4,6,8,10,12,16), bias=8.0, sigma_noise=None, reps=200, seed)`: builds a balanced random design for each grid value (same judges/projects, track-agnostic), uses `estimability` to report median offset SE and detection power per value, and `reviews_needed(power=0.8)` (smallest grid value reaching it, or "> 16"). If `sigma_noise` is None, estimate it from residuals of the fitted additive model on the supplied reviews (pooled residual SD) and report the estimate. Pure, deterministic, < 20 s.
2. Proof section "How many reviews does normalization need?": table reviews-per-judge → median SE → power at 8 points (and at 12), using the fixture's 30 judges / 40 projects and σ_noise estimated from the fixture; one plain sentence of conclusion (e.g. "at ~4 reviews per judge an 8-point harsh judge is caught ~13% of the time; ≈N per judge reaches 80%"). Report whatever the numbers are.
3. Proof block "Judge spread, organizers' definition": sample SD of per-judge mean scores (mean of the 3 criteria, 1–5 scale): all 126 reviews/30 judges = 0.4198 (matches the homepage σ = 0.42 confirmed by the organizers) → after our duplicate policy 0.3292 → after offset removal at the CV-chosen λ, λ=0 and λ=2 (compute). Three sentences explaining the chain and that a smaller spread is not itself evidence.
4. Fix `engine.select_lambda`: when cross-validation produces no predictions (e.g. a single judge or every held-out review lacks training data), return the largest grid λ with `note="cross-validation not possible; most conservative lambda used"`; never NaN; never invalid JSON. Test it.
Tests in tests/test_engine.py for 1 and 4; determinism. Files: src/results/engine.py, scripts/normalization_proof.py, docs/NORMALIZATION-PROOF.md, tests/test_engine.py.
