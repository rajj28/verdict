# Packet P8-PRIZES: prize allocation engine

Model: extend events.Prize with `scope` (overall | track), `places` (int, default 1), `one_per_team` (event-level flag on Event: `one_prize_per_team`, default true), `eligibility_note`. Pure function in src/results/prizes.py: input = official ranked rows (status ranked only; unranked/withdrawn/disqualified/superseded never win), prizes in position order, policy → awards [{prize, place, project, reason}] + unawarded [{prize, reason}]. Rules: overall prizes draw from all ranked projects; track prizes from that track; with one_per_team a team already awarded a higher-position prize is skipped with the reason written ("Glass Signal already won Grand Prize; next eligible is …"); exact ties at the cut (same rounded official score) are reported as "tie requires organizer decision" with both projects, never silently broken. Results preview shows the proposed awards; publication stores them in the snapshot and they are covered by the digest/verify. Public results page lists awards. Tests: overall vs track, one-per-team cascade, tie at the cut, unranked excluded, determinism.
