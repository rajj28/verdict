Rules enforced where curl arrives.

Hiding a button is not a permission system. Every guarantee below is checked on the server for the interface and the API alike, and each one is covered by tests you can run.

Scores that are calibrated, not just averaged

Harsh and generous judges are separated from project quality with a documented additive model. How strongly to correct is chosen by cross-validation, and the choice is recorded with every result.

Judges who can't peek

Isolation lives in the backend policy layer, so a logged-in judge typing another judge's URL gets a 403.
