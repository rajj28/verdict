One command, no loopholes

A submission window is half-open and checked on the server after the row lock, so a late edit is refused at the deadline and not a second later. A judge sees only their own queue, scores and comments — separation of duties is a database constraint on one role per person per event, not a UI convention.

Scores are normalized with per-judge offsets and shrinkage, every publication stores the input set it was computed from with a digest, and any organizer can re-verify a result later. The gallery is public, and that is documented rather than hidden.
